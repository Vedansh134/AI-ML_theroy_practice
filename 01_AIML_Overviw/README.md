## What is Artifical Intelligence ?
- Artificial intelligence (AI) refers to technologies that enable computers to learn, understand, analyze information and perform tasks that typically require human intelligence. 
- AI can help us understand language, process data, solve problems and provide useful recommendations. 
- It can perform a numerous amount of tasks. These include :
   - Reasoning (making decisions)
   - Learning (acquiring knowledge)
   - Perception (understanding images, speech)
   - Natural Language Understanding (processing human language)
   - Problem Solving (finding solutions)

## What is Machine Learning ?
- Machine Learning (ML) is a subset of A.I that gives the ability to machine that learns from the data, analyzie the data without need of any task is explictly design/programmed by programming/coding.
- Basically ML teaches the computer systems/models think and understand the task just like humans are learning by data.
